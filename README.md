# 影片一鍵轉 MP3 工具（自動匹配原影片音訊速率）

這是一個專為 Windows 設計的一鍵轉檔工具，利用 FFprobe 自動解析每部影片的原始音訊參數，並以最精確符合原速率的設定轉換為 MP3。

---

## 核心特色

1. **自動精準匹配音訊位元速率 (Bitrate)**：
   - 透過 `ffprobe` 讀取影片第一音軌的真實位元速率（例如 128 kbps、192 kbps、256 kbps、320 kbps 等）。
   - 自動將目標 MP3 的編碼速率設為完全對應的數值，避免不必要的音質壓縮損耗，也不浪費儲存空間。
2. **原生 MP3 無損直出 (Stream Copy)**：
   - 若來源影片本身的音訊軌本來就是 MP3 編碼，程式會自動啟用 `-c:a copy` 直接提取，**零轉碼失真且瞬間完成**。
3. **智慧回退容錯機制**：
   - 若影片容器（如某些 VBR AAC 的 MP4/MKV）未在中繼資料記錄固定位元速率，程式會自動採用高品質 192 kbps 進行編碼，確保轉檔流程不中斷。
4. **一鍵多用操作方式**：
   - **方式一（拖曳轉檔）**：將一個或多個影片檔案（或整個資料夾）直接拖曳到 `convert_to_mp3.bat` 上放開即可。
   - **方式二（目錄批次轉檔）**：將這兩個腳本放在存放影片的目錄下，直接雙擊 `convert_to_mp3.bat`，即可自動轉換目錄內所有影片。

---

## 檔案說明

- [`convert_to_mp3.bat`](convert_to_mp3.bat)：Windows 快速啟動批次檔，支援滑鼠拖放與 UTF-8 編碼支援。
- [`convert_to_mp3.ps1`](convert_to_mp3.ps1)：核心處理邏輯腳本（呼叫 FFprobe / FFmpeg）。

---

## 前置要求

- 系統需已安裝 **FFmpeg** 與 **FFprobe**，並將其 `bin` 目錄加入系統環境變數 `PATH`。
